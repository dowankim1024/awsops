# 3D 토폴로지 성능 측정

계획서 성공 기준: stress 프리셋(EC2 1,000, 서브넷 30, VPC 2)에서 60fps, 첫 렌더 1초 이내, 드로우 콜 50 이하.
수치는 `/topology-3d`의 성능 HUD(우상단)에서 읽는다. fps는 **5초 벤치마크** 버튼(프레임루프를 `always`로 바꾸고 카메라를 자동 회전)으로 잰다.

## 읽는 법
- **노드 a / b**: 개별로 그린 노드 / 필터 후 노드. 차이는 스택에 접힌 수
- **엣지 a / b**: 그려진 선 / 입력 엣지. 같은 앵커 쌍은 한 선으로 접힌다
- **드로우 콜**은 마지막으로 렌더된 프레임의 `gl.info.render.calls`. 라벨 하나가 드로우 콜 하나다 (troika Text). 라벨 상한 96, 노드 300개 초과 시 서브넷·스택 라벨은 카메라 거리 55 유닛 밖에서 숨긴다
- 정지 상태에서는 렌더가 멈추므로(`frameloop="demand"`) fps는 "정지"로 표시된다. 회전 중이거나 벤치마크 중에만 의미가 있다
- **결과 복사**는 벤치마크 결과 + 레이아웃 통계 + UA를 JSON으로 클립보드에 넣는다. 이 표를 채울 때 쓴다
